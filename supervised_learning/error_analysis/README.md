# Error Analysis

This project covers confusion matrices and the metrics derived from them:
sensitivity, precision, specificity, and F1 score. It also examines bias and
variance when diagnosing machine learning models.

## Files

- `0-create_confusion.py`: builds a confusion matrix from one-hot arrays.
- `1-sensitivity.py`: calculates sensitivity for every class.
- `2-precision.py`: calculates precision for every class.
- `3-specificity.py`: calculates specificity for every class.
- `4-f1_score.py`: calculates the F1 score for every class.
- `5-error_handling`: selects strategies for bias and variance problems.
- `6-compare_and_contrast`: identifies the primary model error.
