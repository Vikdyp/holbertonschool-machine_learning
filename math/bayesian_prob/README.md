# Bayesian Probability

Compute binomial likelihoods and discrete Bayesian updates using NumPy.

- `0-likelihood.py`: binomial probability for each candidate probability.
- `1-intersection.py`: likelihood weighted by a discrete prior.
- `2-marginal.py`: total probability of the observations.
- `3-posterior.py`: prior updated with the observed counts.
- `100-continuous.py`: interval probability for the beta posterior under a
  uniform prior, using only `scipy.special` as required by the advanced task.

Each submission validates the required inputs and exception order.
