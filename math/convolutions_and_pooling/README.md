# Convolutions and Pooling

This project implements two-dimensional convolutions and pooling operations
with NumPy. The functions operate on batches of grayscale or multichannel
images and support valid, same, and custom padding as well as configurable
strides and multiple kernels.

## Tasks

- `0-convolve_grayscale_valid.py`: valid convolution on grayscale images.
- `1-convolve_grayscale_same.py`: same convolution on grayscale images.
- `2-convolve_grayscale_padding.py`: convolution with custom padding.
- `3-convolve_grayscale.py`: strided grayscale convolution.
- `4-convolve_channels.py`: convolution across image channels.
- `5-convolve.py`: convolution with multiple kernels.
- `6-pool.py`: max and average pooling.
